SUPERMARKET BOOST - mod for Supermarket Together

INSTALL (Windows)
  1. Close the game.
  2. Unzip this folder anywhere.
  3. Double-click Install.bat. (If Windows SmartScreen warns, click "More info" -> "Run anyway".)
  4. Start the game from Steam.
  You only do this once: the mod downloads new versions by itself and uses them
  the next time you start the game.

EVERYONE IN THE LOBBY NEEDS THE MOD (for the synced pistol). If you join someone
who does not have it, set MultiplayerSync = false in the config first.

WHAT IT DOES (the HOST's settings count for customers, breakdowns and day speed)
  - About 2x as many customers, arriving about 2x as often. Prices are unchanged.
  - About 3x fewer machine breakdowns (or none, via the config).
  - GAME SPEED button above the open-store switch in the office, or F6:
    the whole store runs x2 -> x4 while you still walk at normal speed (host only).
  - COSMETICS ROOM button in the office, or F8: skins & hats room and back.
  - Main menu: CONTINUE loads your latest store as a friends-only Steam lobby.
    Friends join with Steam's "Join Game" or an invite (F7 in game) - no codes.
  - Pistol: press G with empty hands (a real held item everyone sees), shoot with the
    normal action button, R to reload. 15-round magazine, spare ammo refills every morning.
    Shot people ragdoll and get back up; 3 shots keep a shopper or thief down for good
    (thieves drop their loot). Shoot your friends to ragdoll them. Broom hits ragdoll too.

YOUR SAVES ARE BACKED UP
  Before installing, at every game start and before every save, the save folder is copied to:
  %USERPROFILE%\AppData\LocalLow\DDTNL\Supermarket Together Backups (SupermarketBoost)
  To restore: close the game, copy the files from a backup folder into
  %USERPROFILE%\AppData\LocalLow\DDTNL\Supermarket Together  (replace when asked).
  Steam Cloud may also need you to pick "local files" the next time the game starts.

SETTINGS
  After the first launch, edit:
  <game folder>\BepInEx\config\codescrambler.supermarkettogether.boost.cfg
